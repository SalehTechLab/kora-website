# Awesome Design MD

When designing or implementing web interfaces, use the design guidance from:

https://github.com/VoltAgent/awesome-design-md

Before creating UI, consult the relevant design guidance from the repository when available.

Apply the guidance to:

- Layout and composition
- Typography
- Color systems
- Spacing
- Components
- Responsive behavior
- Interaction patterns
- Accessibility
- Visual hierarchy
- UX details

Prefer the repository's documented design systems and recommendations over generic UI conventions when they are applicable.

Do not blindly copy examples. Adapt the principles to the user's product, brand, and requirements.
